# Prompt patterns

Use these as composition scaffolds, not fixed copy. Preserve the user's direction and remove fields that do not help.

## Standalone hero

```text
Use case: ui-mockup
Asset type: standalone desktop website hero design
Primary request: Create one presentation-ready hero for [product].
Visual signature: [specific material, composition, light, and spatial behavior].
Composition: navigation, headline, supporting copy, primary and secondary actions, and [optional proof strip].
Typography: crisp editorial hierarchy with a protected reading zone.
Material: [folded ribbon / refractive membrane / liquid lens / contour field], including translucency, edge light, depth, and grain.
Text (verbatim): [exact text].
Constraints: show only the hero; realistic desktop proportions; flat readable UI above the material; no code, annotations, device frame, watermark, generic aurora, or unrelated page sections.
```

## Full-page expansion

Use only after the hero is approved or explicitly supplied as approved.

```text
Use case: ui-mockup
Asset type: complete high-fidelity desktop landing-page design
Input image: the approved hero is the binding art-direction reference.
Primary request: Extend the hero into one coherent long-page kit without changing its typography, palette, spacing rhythm, UI tone, or shader material rules.
Sections: trust, product surface, workflow, feature system, automation or process, pricing, testimonials, final CTA, and footer; omit irrelevant sections.
Material progression: define a quieter introduction, several controlled section-specific transformations, one structural connector, one recommended-plan focal treatment, and a broad return of the hero form in the final CTA.
Constraints: several meaningful material uses; protected reading zones; realistic web grid; no generic template sections, dark-theme drift, duplicated compositions, code, annotations, device frames, or watermark.
```

## Targeted revision

Change one design variable at a time. Repeat the invariants explicitly:

```text
Change only [specific issue]. Preserve the approved composition, exact copy, typography hierarchy, palette, material family, spacing, and all other sections unchanged.
```

## Material vocabulary

Prefer observable descriptions:

- **Pearlescent ribbon:** layered translucent folds, spectral edge refraction, satin interior, directional flow.
- **Liquid lens:** localized displacement, magnified boundary, soft caustic highlight, calm surrounding field.
- **Refractive membrane:** thin-film color at grazing angles, quiet center, tension near anchors.
- **Contour field:** coherent directional lines with controlled density and one focal compression.
- **Particle filament:** sparse points aligned along a flow path rather than uniform decorative dust.

Avoid relying on trend labels such as futuristic, holographic, modern, or premium without specifying visible behavior.
